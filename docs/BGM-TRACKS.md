# LUMINA 탐구 영역 BGM

각 탐구 영역은 같은 음량 규칙을 공유하되, 저음 중심·음계·펄스 간격을 달리한
24초 루프를 사용합니다. 모든 파일은 외부 샘플 없이 `scripts/generate-bgm.mjs`가
생성한 절차적 원본이며, 기본 상태는 꺼짐입니다.

| 영역 | 트랙 | 설계 방향 |
| --- | --- | --- |
| 홈 | `home.mp3` | 따뜻한 펜타토닉 패드와 느린 호흡 |
| 사주 | `saju.mp3` | 낮은 공명과 목·토를 연상시키는 둥근 펄스 |
| 점성술 | `astro.mp3` | 공기감 있는 고음과 넓은 간격의 반짝임 |
| 타로 | `tarot.mp3` | 어두운 단3도 패드와 절제된 플럭 |
| 수비학 | `numerology.mp3` | 규칙적인 수열처럼 느껴지는 짧은 음형 |
| Big Five | `psychometrics.mp3` | 분석을 방해하지 않는 중립적 반복 |
| 융 심리 유형 | `jungian.mp3` | 서로 당기는 두 음역의 성찰적 대비 |
| 다크 트라이어드 | `darktriad.mp3` | 낮고 긴장된 저음, 과도한 공포 효과 배제 |
| 애착 유형 | `attachment.mp3` | 안정적인 저음과 느린 왕복감 |
| 정서지능 | `eq.mp3` | 따뜻한 종소리와 열린 장화음 |
| 인지 탐색 | `cognitive.mp3` | 정확한 짧은 펄스와 낮은 밀도의 아르페지오 |
| 오늘의 운세 | `horoscope.mp3` | 가볍고 밝은 고음, 짧은 하루 리듬 |
| 궁합 | `compatibility.mp3` | 두 음정이 함께 울리는 협화 대비 |

## 재생 원칙

- 브라우저 자동재생 정책과 갑작스러운 소리를 피하기 위해 처음에는 재생하지 않습니다.
- 상단 `BGM` 버튼을 누른 뒤에만 재생하며, 선택은 이 브라우저에만 저장합니다.
- 영역을 이동하면 해당 영역의 트랙으로 바꾸고, 트랙을 찾지 못하면 홈 트랙을 사용합니다.
- 오디오 요소의 음량은 최대 음압의 18%로 제한하고, 끄면 즉시 일시정지·소스를 해제합니다.

다시 생성하려면 `pnpm bgm:generate`를 실행하세요. 인코딩에는 로컬 `ffmpeg`의
`libmp3lame` 코덱이 필요합니다.
