# LUMINA 인지능력 파일럿 규준화 분석계획 v1

## 목적과 범위

이 문서는 LUMINA가 직접 작성한 5개 능력 영역(Gf, Gc, Gv, Gwm, Gs)을 한국어 성인
18–64세 표본에서 연구용으로 검증하기 위한 사전등록 계약이다. WAIS/WISC/ICAR의
문항·규준·점수표를 복제하지 않으며, 승인 전에는 IQ나 백분위를 산출하지 않는다.

## 고정 규칙

- 운영 표본과 연구 표본의 동의를 분리한다. 철회된 참여자의 행은 분석 export에서 제외한다.
- 분석 입력은 데이터 사전에 열거된 최소 열만 허용한다. 이름, 이메일, IP, user-agent, URL,
  인증 토큰, 자유서술 개인정보는 금지한다.
- 문항은행·알고리즘·청사진·동의 버전을 고정하고, 한 export에 여러 버전이 섞이면 실패시킨다.
- 개발/holdout을 참여자 기준으로 분리한다. 문항 calibration, 구조·정밀도, retest, DIF,
  외부 준거 타당도가 모두 통과되고 독립 검토가 기록되기 전까지 release status는 candidate다.
- 2PL과 3PL을 사전 지정한 정보기준과 적합도 기준으로 비교한다. 선택 모델과 탈락 사유를
  manifest에 남기며, 단일 지표만으로 모델을 고르지 않는다.
- 일반요인과 영역요인은 확인적 구조 검증 후에만 보고한다. 전체점수 통과만으로 하위점수를
  만들지 않는다.
- 결과 공개 시 평균 100, 표준편차 15의 IQ 척도와 개인 95% 신뢰구간을 사용하되, 임상진단·
  채용·교육 선발·법적 판단에 사용할 수 없다는 제한을 함께 표시한다.

## 표본과 품질

연령대, 성별, 교육수준, 지역, 기기 적격성의 사전 정의된 층화를 사용한다. 결측, 중복 제출,
비정상 소요시간, 키보드·포인터·뷰포트 조건 위반, 문항 노출 이력 위반은 품질 플래그로
분리한다. 합성 fixture는 테스트용으로만 사용하며 실제 표본과 혼동하지 않는다.

## 변경관리

데이터 잠금 뒤 분석 규칙을 변경하면 새 버전의 계획·해시·승인 기록이 필요하고 이전 결과의
릴리스를 차단한다. 원자료는 제한된 연구 저장소에서만 처리하며 Git·공개 정적 자산·로그에
복사하지 않는다.

## 실행 전 자동 검증

R 분석을 시작하기 전에 `pnpm cognitive:validate-export`를 CI 또는 제한된 연구 환경에서
실행한다. 이 사전 검증은 직접 식별자·허용되지 않은 열·혼합 문항은행/알고리즘 버전·중복
assignment·참여자 단위 분할 위반·응답 순서 오류·holdout 누락을 차단한다. 검증 manifest에는
원자료 대신 행 수, 실행 수, 버전, 분할, SHA-256과 규칙 위반 사유만 남긴다. 검증 통과는
규준 승인이나 IQ 공개를 의미하지 않으며, 이후 R 기반 IRT·구조·정밀도·DIF·외부 타당도와
독립 검토 게이트를 모두 거쳐야 한다.
