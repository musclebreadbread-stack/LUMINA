# 인지능력 점수 공개 게이트 운영 절차

이 문서는 파일럿 응답을 IQ 결과로 전환할 때 적용한다.

1. 데이터 사전과 export validator가 허용 열, 동의 버전, 단일 문항은행·알고리즘 버전, holdout 분리를 통과했는지 확인한다.
2. IRT(2PL/3PL), 구조·정밀도, retest/alternate-form, DIF/DTF, 외부 준거 타당도 결과와 산출물 해시를 검토한다.
3. 자동화 release gate가 `candidate`를 만들었는지 확인한다. 자동화 코드는 `approved`를 만들 수 없다.
4. 통계 담당자와 연구 책임자가 독립적으로 승인하고, 승인 시각·버전·해시를 별도 감사 기록에 서명한다.
5. 승인된 규준 payload만 `private_cognitive.norm_releases`에 `approved`로 등록한다. client 코드나 공개 환경변수에 payload를 넣지 않는다.
6. 결과 서버는 완료 실행, 연령 규준, 문항은행·알고리즘 버전이 모두 일치할 때만 IQ·백분위·95% 신뢰구간을 반환한다. 그 외에는 `pilot_withheld`를 반환한다.
7. 문항 수정, 규준 재추정, 분석계획 변경, 철회·공정성 문제 발생 시 이전 릴리스를 폐기하고 새 버전으로 전체 게이트를 다시 수행한다.
