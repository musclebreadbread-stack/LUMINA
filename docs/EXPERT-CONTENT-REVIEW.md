# LUMINA 전문가 콘텐츠 검수 보고서

검수일: 2026-08-30
검수 상태: 문헌·코드 기반 사전 검수 완료 / 심리측정·상담·명리 분야 인간 전문가의 최종 승인 대기

이 문서는 실제 자격 보유 전문가의 서명이나 한국어판 척도의 타당화 결과를 의미하지 않는다. 공개 문헌과 현재 구현을 대조해, 화면이 근거보다 강하게 말하지 않는지와 사용자가 결과를 낙인·진단으로 오해할 가능성을 줄였는지 기록한 릴리스 전 검토표다.

## 이번 검수에서 반영한 수정

1. 다크 트라이어드의 한국어·영어 소개 문구를 한국판 연구의 2요인 결과까지 포함하도록 구체화했다. “한국어 번역과 요인 구조가 검증되지 않았다”는 포괄 문구 대신, 현재 3요인 구현이 한국 표본에서 검증된 결과가 아니라는 점을 분명히 한다.
2. 다크 트라이어드의 규준 출처를 “내부 참고 표본”이 아니라 OpenPsychometrics 공개 참고 표본으로 명시했다.
3. IPIP 공식 웹 참고표에 확인되지 않은 발행 연도 `2026`을 붙이지 않도록 인용 타입에서 `n.d.`를 허용했다.
4. 애착 문항의 확인 가능한 한국어 문장 오류와 영어 구두점 오류를 고쳤다. 애착 유형 설명은 사람의 가치·병리·의존성을 단정하지 않도록 완화했다.
5. 통계 그래프는 장식 이미지와 근거 수치를 섞지 않는다. 관측 원점수, 측정오차 참고 구간, 실제로 존재하는 참고 표본만 별도 표시하고, 규준이 없는 축에는 규준·백분위를 만들지 않는다. 그래프에는 표 형태의 대체 읽기와 한계 문구를 함께 둔다.

## 최종 전문가 확인이 필요한 항목

- 심리측정 전공자가 한국어 문항의 의미 동등성, 응답척도 선택, 역채점, 요인 구조와 사용 목적을 독립적으로 확인한다.
- SD3·SSEIT·ECR-R 관련 문항의 상업적 사용 권한과 번역·재현 조건을 권리자 기준으로 확인한다. 현재 카탈로그의 `permission-required` 표시는 승인 완료를 뜻하지 않는다.
- 한국판 SD3의 2요인·17문항 연구를 현재 27문항 3요인 화면에 적용할지, 원척도 탐색을 유지할지 전문가와 제품 책임자가 결정한다.
- 애착의 유형명·상담 안내·성인 관계 문항 및 다크 트라이어드의 민감 문항이 낙인, 임상 진단, 범죄성 판단으로 읽히지 않는지 상담·윤리 검토를 받는다.
- 사주·점성술·궁합의 전통 용어와 유파 표기를 명리 연구자에게 확인하고, 계산 정확도와 상징 해석의 주장 범위를 계속 분리한다.
- 인지 파일럿은 한국 성인 표본의 문항 보정, 구조·신뢰도·재검사·DIF/공정성·외적 타당도와 독립 서명이 끝날 때까지 `pilot_withheld`를 유지한다.

## 운영 판정

이번 검수와 결과 시각화 변경은 로컬 코드·메시지·정적 자산만 바꾸며 DB 스키마나 RLS 정책을 추가하지 않는다. 인지 파일럿의 기존 Neon 마이그레이션 상태는 별도 읽기 전용 확인 대상이며, 이 변경을 이유로 기존 마이그레이션을 재실행하거나 문항을 적재하지 않는다. Production 배포 후에도 위의 전문가 승인 대기 상태는 유지되어야 한다.
