# 인지능력 탐색의 표준화 온라인 검사 전환 설계

## 1. 목적과 결정

LUMINA의 `인지능력 탐색`을 한국 성인(만 18–64세)을 위한 표준화 온라인 검사로 전환한다. 최종 목표는 원점수 합계가 아닌 규준 기반의 `LUMINA 연구용 IQ 추정치`를 제공하는 것이다.

이 점수는 공개 전의 규준화·신뢰도·타당도·공정성 검증을 통과한 LUMINA 고유 척도다. WAIS/WISC 또는 다른 상용·임상 검사의 문항, 규준, 상표를 복제하거나 그 검사와 동등하다고 주장하지 않는다. 임상 진단, 채용, 교육 선발, 법적 판단에는 사용할 수 없다.

표준화 연구가 완료되기 전에는 IQ, 백분위, z점수, T점수, 능력 순위를 계산하거나 노출하지 않는다. 이 원칙은 현재 탐색형 구현의 규준 부재 방침을 유지·확장한다.

## 2. 현재 상태와 교체 범위

현재 구현은 LUMINA가 작성한 16문항의 ICAR 형식 탐색이다. 수열·행렬추론·언어추론·3차원 회전의 네 형식을 사용하며, 전체 및 형식별 정답률만 제공한다.

다음 현재 구조는 점수용 검사에서 교체한다.

- 고정된 `ITEMS` 배열과 클라이언트 번들 내 정답 키
- 응답 전체를 결과 URL에 담는 `cognitiveCode` 방식
- 결과 화면의 문항별 정답·규칙 복기와 응답 공유
- 16문항 완료만으로 결과를 산출하는 채점 엔진

시각 자극의 인라인 SVG 렌더링, 한 문항씩 진행하는 UI, 키보드 접근성 패턴은 재사용 후보이나, 점수용 자극과 연습용 자극의 데이터·경로는 분리한다.

## 3. 측정 구성과 결과 계약

### 3.1 측정 구성

전체 인지지수의 근거가 되는 계층적 일반인지능력(`g`) 모델을 검증한다. 출제 청사진은 다음 다섯 넓은 능력을 포함한다.

| 지표 | 내용 | 초기 문항 형식 |
| --- | --- | --- |
| Gf 유동추론 | 새로운 규칙과 관계 추론 | 행렬, 수량·기호 규칙, 논리추론 |
| Gc 언어/결정지능 | 한국어 어휘·관계·이해 | 어휘, 유추, 짧은 지문 추론 |
| Gv 시공간 처리 | 시각 패턴과 공간 관계 | 도형 변환, 공간 관계, 정신 회전 |
| Gwm 작업기억 | 정보의 유지·갱신·조작 | 순서 기억, 갱신, 규칙 기반 기억 |
| Gs 처리속도 | 단순 시각 탐색과 기호 판단의 속도 | 표준 장치 조건의 시간 제한 탐색 |

Gs는 브라우저·입력장치·네트워크 조건의 영향을 별도로 검증한다. 해당 조건이 표준화 기준에 맞지 않으면 Gs와 전체 인지지수를 강제로 계산하지 않는다.

### 3.2 결과 계약

공개 기준을 충족한 실행에만 아래를 제시한다.

- 전체 인지지수: 연령 규준 평균 100, 표준편차 15
- 개인별 95% 신뢰구간과 동연령 한국 성인 백분위
- 신뢰도·정밀도 기준을 통과한 하위지수
- 표준화 조건 충족 여부와 결과 해석 한계

예시는 `전체 인지지수 108 (95% CI 101–115)`처럼 제시한다. 점수만 제시하거나 과도한 서열·낙인 표현을 사용하지 않는다.

파일럿, 비표준 장치, 중단된 실행, 미보정 문항이 포함된 실행은 `연구 참여 완료` 또는 `연습 결과`만 제공한다. IQ와 백분위는 보류한다.

## 4. 문항은행과 출제 설계

### 4.1 문항의 생성·검토·상태

각 문항은 공개 또는 검증 가능한 근거, 작성자, 검토자, 언어판, 시각 자극 버전, 정답, 난이도·변별도 보정값, 노출 상태, 폐기 사유를 버전 단위로 가진다.

문항 상태는 `draft`, `expert_review`, `cognitive_interview`, `pilot`, `calibrated`, `active`, `retired`로 구분한다. `calibrated` 이전 상태의 문항은 실점수 출제 대상이 아니다. 상용·비공개 검사 문항의 재현, 기억 기반 복원, 무단 번역은 금지한다.

AI 생성물은 검증 후보 초안일 뿐이다. 전문가 검토와 인지면담, 파일럿 보정을 거치지 않은 생성 문항은 점수은행에 넣지 않는다.

### 4.2 적응형·무작위 출제

매 평가를 다르게 만드는 방법은 무제한 임의 추출이 아니라 다음 순서다.

1. 서버가 평가 실행마다 불변의 무작위 시드와 출제 청사진을 생성한다.
2. 각 영역의 최소 문항 수, 난이도 분포, 형식 균형, 최근 출제 이력, 문항 노출률을 만족하는 후보만 남긴다.
3. 초기에는 중간 난이도 문항을 낸 뒤, 매 응답 후 IRT 능력 추정치와 측정정보를 갱신한다.
4. 현재 능력치에서 정보량 상위 randomesque 후보(최대 5개) 중 서버 시드로 하나를 선택한다.
5. 영역별 최소 조건과 목표 표준오차를 만족하거나 최대 문항 수에 도달하면 종료한다.

따라서 서로 다른 문항 세트라도 같은 척도에서 비교 가능해야 하며, 문항 노출률·대안형 동등성·재검사 효과를 통계적으로 감시한다.

### 4.3 연습은행 분리

점수은행의 정답, 규칙 설명, 보정값은 공개하지 않는다. 현재처럼 문항별 정답과 해설을 보려는 사용자를 위해 같은 시각 언어의 독립 연습은행을 제공한다. 연습 문항과 점수 문항은 ID, 자산, URL, 분석 데이터에서 섞이지 않는다.

## 5. 그림·공간 문항 설계

그림 문항은 장식 이미지나 AI 래스터 이미지를 사용하지 않는다. 하나의 선언형 도형 데이터에서 문제 자극·보기·접근성 설명을 일관되게 생성하는 벡터 SVG로 재작성한다.

- 행렬: 동일한 격자 크기, 높은 명암 대비, 명시적 빈 칸, 색 이외의 윤곽·채움·패턴 차이
- 공간회전: 고정 투시, 일관된 광원·선 굵기, 가려진 면과 연결 관계가 분명한 등각 도형
- 반응 UI: 보기마다 44px 이상의 포인터·키보드 조작 영역, 확대·축소 대응, 색각 이상에서도 구분 가능한 패턴
- 대체 텍스트: 문제 요구와 보기 위치를 설명하되 정답 규칙은 누설하지 않음

전문가 검토 후 대상자 인지면담에서 오해·문화 편향·시각적 모호성이 나타난 문항은 수정 후 재검증하거나 폐기한다.

## 6. 서버·데이터·보안 경계

### 6.1 컴포넌트 경계

- 서버 전용: 문항 선택, 정답 키, IRT 보정값, 채점, 결과 확정, 문항 노출 통제, 연구 집계
- 클라이언트 컴포넌트: 동의 UI, 시간 표시, 자극 렌더링, 응답 제출, 중단 후 재개 UX

점수용 자극에 필요한 문제·보기만 클라이언트에 전달한다. 정답, 보정값, 다른 후보 문항, 원문 문항은행은 어떤 클라이언트 번들·URL·공유 카드에도 포함하지 않는다.

### 6.2 Supabase 데이터 경계

익명 Supabase Auth 주체를 사용해 가입 없이 `auth.uid()`에 실행을 귀속한다. 모든 공개 스키마 테이블은 RLS를 활성화하고, 필요한 동작만 최소 권한으로 부여한다.

| 데이터 | 접근 원칙 |
| --- | --- |
| 평가 실행·사용자 결과 | 본인의 실행만 생성·조회·재개 가능 |
| 응답 제출 | 소유 실행의 현재 배정 문항에만 서버 검증을 거쳐 가능 |
| 점수용 문항 원문·정답·IRT 보정값 | 비공개 스키마 및 서버 전용 |
| 연구 동의·가명 연구 데이터 | 명시적 동의가 있는 가명 주체만, 운영 결과와 분리 |
| 운영 연구 집계 | 서버 전용 최소 인원; 사용자 API로 노출 금지 |

service_role은 서버 전용 집계·보정 작업에서만 사용하며 클라이언트 코드, 로그, 공유 링크, 환경변수 노출 지점에 절대 두지 않는다. RLS는 테이블별 allow/deny SQL 테스트를 작성해 검증한다.

### 6.3 개인정보와 동의

운영 점수와 연구 참여를 분리한다. 연구 참여는 별도 동의 버전, 철회 절차, 보관 기간, 비식별화 전환, 접촉 정보의 분리 보관을 정한 뒤에만 시작한다. 연령대·학력·기기 조건은 연구 목적상 필요한 최소 범위로만 수집한다.

대표 규준 조사, 외부 검사 수렴타당도 연구, 미성년 포함 확대는 연구윤리 및 법률 검토를 완료한 후에만 시작한다. 현재 범위에는 미성년자를 포함하지 않는다.

## 7. 표준화·타당화 연구

### 7.1 순서

1. 측정 청사진, 가설, 제외 기준, 점수 공개 기준을 사전등록한다.
2. 내용 전문가 검토와 한국 성인 인지면담으로 문항 이해도·번역·접근성 문제를 확인한다.
3. 불완전 블록 파일럿으로 문항 보정, 모형 적합도, 노출·시간·기기 품질을 분석한다.
4. 연령·성별·학력·권역을 고려한 층화 규준 표본을 수집한다.
5. 독립 표본에서 교차검증, 대안형 동등성, 재검사 신뢰도, 집단별 DIF를 검증한다.
6. 적법하게 시행한 한국어 성인 인지검사와의 수렴·판별 타당도를 검증한다.
7. 사전등록 기준을 모두 통과한 문항·보정값·규준 버전만 배포한다.

필요 표본 수와 각 셀의 최소 규모는 목표 측정오차, 예상 문항 모수, DIF 분석력, 결측·이탈률을 반영한 시뮬레이션으로 연구 시작 전에 확정한다. 임의의 단일 표본 수만으로 표준화를 선언하지 않는다.

### 7.2 공개 기준

공개 전 아래 증거를 문서화한다.

- 전체 및 하위구성의 요인구조·측정불변성·국소 독립성
- IRT 문항 적합도, 문항정보, 노출률, 대안형 동등성
- 전체 및 개인 수준의 신뢰도/조건부 표준오차
- 연령 규준의 대표성·홀드아웃 재현성·백분위 안정성
- 연령대·성별·학력·장치 조건에서의 DIF와 수정·폐기 기록
- 재검사 신뢰도와 외부 준거에 대한 수렴타당도

실패한 기준은 사후에 완화하지 않는다. 문항 폐기, 청사진 수정, 추가 표본 수집 또는 점수 비공개 중 하나를 선택한다.

## 8. 사용자 경험과 결과 표현

### 8.1 검사 전·진행 중

검사 시작 전 연구/운영 동의, 지원 장치 확인, 무점수 튜토리얼, 접근성 안내를 제공한다. 튜토리얼은 실제 점수은행과 격리한다. 평가 진행 중에는 남은 문항 수가 아니라 상태·중단 및 재개 가능 여부를 보여 주며, 필요 없는 경쟁·서열 표현을 피한다.

### 8.2 결과

표준화 조건이 충족된 결과는 전체 인지지수, 95% 신뢰구간, 백분위, 조건부로 허용된 하위지수, 규준 버전, 표준화 상태, 재검사 안내를 보여 준다. 결과 공유는 기본 비활성화하고, 사용자가 선택한 경우에도 원점수·문항·응답·세부 인구통계는 공유하지 않는다.

점수보다 먼저 다음을 읽을 수 있어야 한다.

- 이 값이 LUMINA 연구용 표준화 추정치라는 사실
- 신뢰구간과 재검사·연습 효과
- 임상 진단·선발·채용 판단이 아니라는 한계
- 표준화 조건이 맞지 않아 점수를 보류한 사유

## 9. 검증 계획

### 9.1 자동 테스트

- 단위 테스트: 문항 생성, 정답, 보정값 범위, IRT 추정, 청사진 충족, 노출 통제, 점수 보류 조건
- 데이터베이스 테스트: 각 테이블의 RLS select/insert/update/delete 허용·거부, 주체 간 격리, 비공개 데이터 비노출
- E2E 테스트: 서로 다른 두 실행의 문항 세트 차이와 청사진 충족, 중단·재개, 키보드, 모바일·확대, 축소 모션, 점수 보류
- 보안 회귀: URL·공유 카드·클라이언트 번들에 정답·IRT 보정값·원 응답·비밀키가 없는지 검사
- 통계 재현성: 버전 고정 문항·규준·시드·분석 스크립트로 보정 결과를 다시 산출

### 9.2 배포 전 게이트

`pnpm typecheck`, `pnpm lint`, `pnpm test`, 단일 워커 Playwright, `pnpm build`를 모두 통과해야 한다. 표준화 결과 릴리스에는 자동 테스트 외에도 연구 분석 보고서와 심리측정 전문가 검토를 요구한다.

## 10. 구현 순서

1. 사전등록 가능한 측정·연구 프로토콜과 문항 작성 가이드 작성
2. Supabase 스키마·RLS·서버 전용 경계 설계 및 검증용 마이그레이션 작성
3. 점수은행·연습은행 모델, 벡터 그림 렌더러, 문항 검토 워크플로우 구현
4. 익명 인증 기반의 평가 실행·적응형 출제·재개·점수 보류 흐름 구현
5. 파일럿 수집과 오프라인 통계 분석 파이프라인 구축
6. 규준화·타당화 통과 후 결과 리포트와 제한된 공유 기능 공개

마이그레이션 실행, 실사용자 표본 수집, 외부 전송, 배포는 각각 별도 사람 승인을 받은 뒤에만 수행한다.
