# 인지능력 문항 작성·검토 규칙

표준화 점수에 사용하는 문항은 LUMINA가 직접 작성한 원문 문항만 사용한다. WAIS, WISC, ICAR 등 저작권이 있는 문항을 복사·번역·재현하지 않으며, 공개 연습 문항과 비공개 점수 문항은 별도 namespace로 관리한다.

## 문항 기록 필드

- 측정 구인(construct tag): `gf`, `gc`, `gv`, `gwm`, `gs` 중 하나
- 한국어 원문과 영어 번역 상태
- 정답 근거와 오답 선택지별 오답 유도 이유
- 도형·공간 문항의 시각 접근성 점검(색상만으로 구분하지 않음, 대비, 대체 텍스트)
- 서로 독립적인 전문가 2명 이상의 검토 기록
- 인지 인터뷰 기록(문항을 어떻게 해석했는지)
- 저작권·출처(provenance)
- 문항 보정 모형(2PL/3PL), 표본 수, 보정 버전
- 폐기 문항의 사유와 날짜

## 승격 절차

작성 → 번역 역번역 점검 → 인지 인터뷰 → 전문가 독립 검토 → 파일럿 자료 수집 → IRT 보정 → 문항 정보·DIF·노출률 검토 → `active` 승격 순서로 진행한다. `active` 문항은 보정 모수와 승인된 보정 버전이 없으면 로더가 거부한다.

파일럿 단계의 정답률은 연구 분석용 원자료로만 보관한다. 승인된 한국 성인 규준과 릴리스 게이트가 없는 동안 사용자 화면에는 IQ, 백분위, 하위지수 또는 정답 해설을 표시하지 않는다.
