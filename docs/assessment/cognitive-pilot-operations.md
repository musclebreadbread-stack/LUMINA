# 인지능력 표준화 파일럿 운영 체크리스트

이 문서는 현재 파일럿의 운영 경계와 승인 순서를 고정한다. 파일럿은 문항·응답 데이터의 타당화 단계이며, 개인의 능력 서열이나 임상 판단을 제공하지 않는다.

## 시작 전

- 연구계획서와 분석계획을 사전 등록하고, 한국 성인 18–64세의 포함·제외 기준을 공개한다.
- 모집 공고는 보상·대상·소요 시간·익명 저장·철회 방법·문의 채널만 안내한다. 점수나 진단을 약속하지 않는다.
- 문항마다 원문·번역·오답 근거·접근성·저작권 출처·전문가 2인 검토·인지 인터뷰·보정 버전을 확인한다.
- `active` 승격 문항의 노출률과 최근 출제 이력을 검토하고, 정답 키·IRT 모수·시드는 비공개 스키마에 둔다.
- 익명 Auth와 RLS 허용·거부 테스트 결과를 보관한다. 브라우저에는 발표 DTO만 전달한다.

## 참가자 지원과 철회

- 지원 티켓에는 실행 ID와 오류 시각만 받고 원문 응답·정답·시드를 요청하지 않는다.
- 운영 저장 동의와 연구 참여 동의를 별도로 기록한다. 연구 참여 철회는 이후 분석 제외 플래그를 남기며 다른 참가자 자료나 집계 결과를 수정하지 않는다.
- 모바일·작은 화면·키보드/포인터가 없는 환경에서는 처리 속도 영역과 종합 해석을 보류한다. 이를 능력 부족으로 표현하지 않는다.

## 사고 대응

- 답안 키·시드·원자료 노출 의심 시 즉시 출제를 중지하고, 세션·문항 버전을 격리한 뒤 접근 로그와 RLS 정책을 보존한다.
- 잘못된 문항·번역·그림은 `retired` 처리하고 사유와 영향 범위를 기록한다. 이미 수집한 응답은 재분석 전까지 점수로 공개하지 않는다.
- 개인정보가 수집된 사실을 발견하면 해당 배포를 중단하고 최소 수집 원칙에 따라 삭제·통지 여부를 책임 연구자가 결정한다.

## 공개 금지와 승인 게이트

다음 네 가지 승인은 서로 독립적으로 필요하다.

1. 로컬/스테이징 Supabase 마이그레이션 적용 승인
2. 연구 참가자 모집·자료 수집 승인
3. 원자료 추출·보정·규준화 분석 승인
4. 표준화 점수(IQ·백분위·신뢰구간) 공개 승인

한국 성인 규준, 신뢰도·재검사·대안형, 구조 타당도, DIF/공정성, 외적 준거 타당도, 독립 검토가 모두 완료되기 전에는 `APPROVED_NORM_VERSIONS`가 비어 있어야 한다. 따라서 현재 모든 점수 경로는 `pilot_withheld`로 끝난다.
