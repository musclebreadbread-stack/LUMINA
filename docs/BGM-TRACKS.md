# LUMINA BGM

사이트 전체가 하나의 재생목록을 공유합니다. 두 트랙을 순서대로 재생하고,
마지막 트랙이 끝나면 첫 트랙으로 돌아가 계속 반복합니다.

| 순서 | 파일 |
| --- | --- |
| 1 | `public/audio/bgm/track-1.mp3` |
| 2 | `public/audio/bgm/track-2.mp3` |

## 재생 원칙

- 브라우저 자동재생 정책과 갑작스러운 소리를 피하기 위해 처음에는 재생하지 않습니다.
- 상단 `BGM` 버튼을 누른 뒤에만 재생하며, 선택은 이 브라우저에만 저장합니다.
- 페이지를 이동해도 재생 중인 트랙과 순서를 그대로 유지합니다(영역별 트랙 전환 없음).
- 트랙이 끝나면 자동으로 다음 트랙을 재생하고, 마지막 트랙 다음에는 첫 트랙으로 돌아갑니다.
- 오디오 요소의 음량은 최대 음압의 18%로 제한하고, 끄면 즉시 일시정지·소스를 해제합니다.

트랙을 교체하려면 `public/audio/bgm/track-1.mp3` / `track-2.mp3` 파일을 새 오디오로
바꾸고 `src/lib/bgm.ts`의 `BGM_PLAYLIST`를 필요에 맞게 갱신하세요.
