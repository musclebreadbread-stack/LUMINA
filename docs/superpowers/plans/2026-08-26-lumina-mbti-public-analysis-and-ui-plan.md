# LUMINA MBTI 공개 분석·결과 UX 개정 계획

> 작성일: 2026-08-26
>
> 상태: 구현 반영 중
>
> 결정: 공개 명칭은 `MBTI 유형 분석(비공식)`으로 통일하고, 내부 호환 키 `jungian`과 순수 계산 함수명은 유지한다.

## 목표

기존 IPIP-50 응답 흐름을 유지하면서 사용자가 MBTI 네 글자를 공식 판정으로 오해하지 않도록 분석 경로와 결과 해석을 다시 설계한다.

1. 홈 카드·메타데이터·검사 진입·결과·용어집·방법론·참고문헌의 공개 문구를 MBTI 선호 축(E/I·S/N·T/F·J/P) 중심으로 통일한다.
2. Big Five 점수 → 네 선호 축 → 경계 확인 → 유형 코드 → 자기성찰 실험이라는 계산·해석 경로를 화면에 공개한다.
3. 연속 점수·95% 참고 범위·`?` 경계 표시를 네 글자보다 먼저 읽도록 안내해 과도한 결정론을 막는다.
4. 공식 MBTI® 검사·문항·규준이 아니라는 상표·방법론 고지를 랜딩과 결과 양쪽에 유지한다.
5. 밝은 `reading-panel` 위에서 어두운 텍스트를 사용하는 CTA 체계를 적용하고, 보조 링크의 가시성·포커스·실제 이동을 회귀 테스트로 고정한다.

## 구현 경계

- 계산 엔진의 내부 `jungian` 키, 파일명, 저장 결과 URL은 기존 링크·테스트 호환성을 위해 변경하지 않는다.
- 공개 문구는 MBTI로 개정하되, Big Five에서 선형 참고 해석한 파생 결과라는 사실을 숨기지 않는다.
- 공식 MBTI 문항·규준·인증을 제공한다고 표현하지 않는다.
- Supabase, RLS, 마이그레이션, 외부 전송, 배포는 이번 범위에 포함하지 않는다.

## 화면 흐름

`50문항 응답` → `Big Five 요인 점수` → `네 선호 축의 연속 위치` → `95% 참고 범위와 경계 ?` → `네 글자 요약 코드` → `유형 프로필·강점·주의점·작은 실험 질문`

랜딩에는 세 단계 카드(문항에 답하기 / 네 선호 축 확인하기 / 코드로 실험하기)를 배치하고, 결과에는 “네 글자보다 네 축을 먼저” 읽는 순서를 별도 안내한다.

## 근거·한계

McCrae·Costa(1989)의 비교 연구는 축 대응을 위한 문헌 참고로만 사용한다. Pittenger(1993), Stein·Swan(2019)의 비판과 IPIP-50의 모집단·번역 한계를 함께 표시한다. 분석 상태는 계속 `derived`로 유지한다.

## 검증 기준

- 한국어·영어 메시지 키 집합과 자리표시자 완전 일치
- 공개 메시지에 이전 `융 유형 렌즈` 문구가 남지 않음
- 네 축·경계·공식 MBTI® 고지·MBTI 결과 읽기 안내가 E2E에서 보임
- 밝은 카드의 보조 CTA가 `rgb(18, 16, 13)` 텍스트로 보이고 `/psychometrics?to=types`로 이동
- `pnpm typecheck`, `pnpm lint`, 관련 Vitest, MBTI E2E, `pnpm build` 통과
