# LUMINA 타로 카드 이미지 생성 프롬프트 (78장)

## 사용법
1. 아래 각 카드의 **프롬프트를 그대로 복사**해서 Google Antigravity(Gemini)에 붙여넣어 이미지를 생성합니다.
2. 생성된 이미지를 **파일명 그대로** `public/tarot/cards/` 폴더에 저장합니다. (폴더는 이미 만들어 두었습니다.)
3. 세로(2:3 비율) 이미지로 생성해 주세요. 배경/프레임까지 포함해서 카드 한 장 전체가 보이도록 요청하면 됩니다.
4. 78장을 전부 저장하시면 알려주세요 — 그 결과물로 타로 결과 화면에 카드 이미지를 표시하도록 이어서 작업하겠습니다.

## 스타일 원칙 (모든 프롬프트에 이미 포함되어 있음)
- 손으로 그린 먹빛 수묵화(ink-wash) 느낌
- 색은 낡은 보석톤(짙은 남색, 그을린 적갈색, 고풍스러운 금빛 황토, 녹청색, 아이보리) — 채도 낮고 세월이 묻은 느낌
- 오래된 한지/양피지 질감 배경
- 은은한 목판화 테두리
- **이미지 안에 글자·숫자·워터마크는 절대 넣지 않음** (앱에서 텍스트를 따로 얹습니다)
